# 先生の書き方（トーン）

授業資料の本文を新しく書く時に、既存の資料と同じ「先生の声」になるようにするためのメモ。

このファイルの内容は、実際に先生が書いた既存9コースの資料を数えて抜き出したもの。
新しく書いた文章がここから外れていたら、既存資料に寄せる。

## いちばん大事なこと

**中学生に、先生が目の前で話しかけているように書く。**

説明書ではなく、授業中のしゃべりをそのまま文字にした感じ。
硬い言い回しや、教科書のような書き方は使わない。

## 文末の型（実際の出現数）

| 型 | 回数 | 使いどころ |
| :--- | ---: | :--- |
| 〜しましょう | 207 | 操作をうながす時。**これが基本** |
| 〜ですね | 29 | 説明のあとの確認・共感 |
| 〜と思います | 18 | 断定を避けてやわらげる |
| 〜してみてください | 15 | 課題・エクストラ課題をふる時 |

- 命令形（「〜しろ」「〜せよ」）は使わない
- 「〜すること」のような箇条書き調の言い切りも使わない
- 敬体（です・ます）で統一する

## 接続の癖

**「なので」が73回**と圧倒的に多い。「したがって」「ゆえに」は使わない。

```
今は歩いている時だけなので、キーを押している間は移動速度が上がり、離したら戻るようにします。
```

ほかに「ただ」「しかし」「でも」。話し言葉寄りのものを選ぶ。

## 感嘆符

「！！」が44回、「！！！」が13回。**ためらわずに使う。**

- 大セクションの見出し：`# 終了！！`
- 盛り上がるところ：「いよいよ今日の一番大事なところです！」
- 課題をふる時：「調べてみて下さい！！」

ただし1つの段落に何度も入れない。ここぞという所で使う。

## 一人称と呼びかけ

- 自分のことは **「先生」**（「先生は10と0.2を入れています」）
  - 既存資料には「私」「自分」も混ざっているが、新しく書く時は「先生」に寄せる
- 生徒のことは **「皆さん」「みんな」**
- 「君」「あなた」は使わない

## 先生の実例を出す

設定値や見た目の選択は、正解を押しつけずに**先生の例**を見せる。

```
それぞれ好きな値を入れてみて下さい！先生は10と0.2を入れています。
先生はコウモリと恐竜っぽいキャラクターを追加してみました。
```

## 正直に言う

難しいこと・面倒なことは、ごまかさずに言う。

```
ちょっと難易度は高め。
今日はメッセージが沢山出てきて、混乱したところもあったと思います。
高校の勉強なので難しいですが、AIなどに聞きながらやってみましょう！！
```

## 学校の勉強とつなげる

算数・数学・理科と結びつけて、「これ学校で習うやつだ」と気づかせる。

```
（”√(ルート)”というのは中学3年生の数学で出てくるものなので、興味が湧いたら予習してみるといいかも）
これは算数・数学で出てくる「座標」とまったく同じ考え方です。
```

## ゲームの作り手としての話をする

ただ操作を教えるだけでなく、**なぜそう作ると面白いのか**を混ぜる。

```
少しずつ難しくするのが、面白いゲームを作るコツですね！
当たり判定は、少し甘くしておく方が気持ちいいことが多いです。
プロのゲームでも、見た目の絵と当たり判定の大きさをわざと変えていることがよくあります。
```

## 波ダッシュでやわらげる

回の締めや次回予告は「〜」で終えると、先生らしい柔らかさが出る。

```
次回は敵を作っていきましょう～
ひとまずは、桜井さんの動画を見るところから始めてみましょう～
```

## 英単語は必ず意味を添える

変数名・ブロック定義名を出す時は、英単語の意味をその場で説明する。

```
名前は”MoveSpeed”にします。意味はそのまま「移動のスピード」ですね。
名前は”EnemyHealth”にします。Enemyは「敵」、Healthは「体力」なので、「敵の体力」という意味ですね。
```

## やってはいけない書き方

- 「〜する必要があります」だけで終える（なぜ必要かを先に言う）
- 専門用語をいきなり出す（先に日本語で言ってから用語を出す）
- 長い一文（1文は2行以内に収める。改行で区切る）
- 生徒を試すような言い方（「分かりますか？」「覚えていますか？」）
