# ブロック定義

ブロック定義とは、**自分だけのオリジナルのブロックを作る**機能のことです。

いくつかのブロックをまとめて一つの名前を付けると、ピンク色の新しいブロックとして使えるようになります。

![image.png](/lessons/scratch-wiki/10/image.png)

## なぜ使うの？

### 同じプログラムを何回も書かなくてよくなる

例えば「歩く速さに戻す」という処理を、ゲームの中の3か所で使っているとします。

ブロック定義を使わないと、速さを変えたくなった時に3か所とも直さないといけません。
1か所直し忘れると、そこだけ違う速さになってしまうバグの原因になります。

ブロック定義にまとめておけば、**直すのは定義の中の1か所だけ**で済みます。

### プログラムが読みやすくなる

“Initialize”（初期化する）や”Spawn”（出現させる）のように名前を付けておくと、
プログラムを見ただけで「ここで何をしているか」が分かります。

ブロックがずらっと並んでいるより、
「Initialize」「Move」と書いてある方がずっと読みやすいですよね。

## 作り方

1. ブロックのカテゴリから”ブロックを作る”ボタンを押す
2. 名前を付ける（英語で、何をするブロックか分かる名前にする）
3. OKを押すと、”定義 ◯◯”というピンク色のブロックが現れる
4. その下にやりたい処理を繋げる
5. 使いたい場所に”◯◯”ブロックを置く

## 引数を付けるともっと便利

ブロック定義には「引数」という値を渡す入り口を付けられます。

これを使うと”Spawn 1”“Spawn 2”のように、
同じブロックを違う値で使い分けられるようになります。

[引数](wiki:引数（ひきすう）)

## 名前の付け方のコツ

授業では英語で名前を付けています。よく使う名前を挙げておきます。

| 名前 | 意味 |
| :--- | :--- |
| Initialize | 初期化する |
| Move | 移動する |
| Spawn | 出現させる |
| Shot / Shoot | 撃つ |
| SetXxx | ◯◯を設定する |
