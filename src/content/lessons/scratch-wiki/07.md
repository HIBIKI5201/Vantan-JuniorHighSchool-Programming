# 座標（ざひょう）

座標（ざひょう）とは、「どこにいるか」を数字で表したものです。

Scratchでは横の位置を**x座標**、縦の位置を**y座標**と呼びます。

## Scratchの画面の広さ

Scratchのステージは、真ん中が x = 0、y = 0 です。

| 場所 | x座標 | y座標 |
| :--- | :--- | :--- |
| 真ん中 | 0 | 0 |
| 右の端 | 240 | - |
| 左の端 | -240 | - |
| 上の端 | - | 180 |
| 下の端 | - | -180 |

つまり横は-240〜240、縦は-180〜180の範囲ということですね。

右に行くほどx座標が大きく、上に行くほどy座標が大きくなります。
**左と下はマイナス**になるのがポイントです。

## よく使うブロック

- **x座標を◯、y座標を◯にする** … その場所へ一瞬で移動する（位置を決める時）
- **x座標を◯ずつ変える** … 今の場所から横に動かす（移動の時）
- **y座標を◯ずつ変える** … 今の場所から縦に動かす（移動の時）

「〜にする」は場所そのものを決めるブロック、
「〜ずつ変える」は今の場所から動かすブロック、という違いに注意しましょう。

下に落ちていく動きを作りたい時は、y座標をマイナスの数だけ「ずつ変える」ことになりますね。

## 算数との関係

これは算数・数学で出てくる「座標」とまったく同じ考え方です。

中学1年生で習う「比例と反比例」のグラフや、中学2年生の「一次関数」でも同じものが出てきます。
Scratchで先に慣れておくと、数学の授業がとても分かりやすくなりますよ！
