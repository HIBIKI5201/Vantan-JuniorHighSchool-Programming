# 当たり判定（あたりはんてい）

当たり判定（あたりはんてい）とは、**キャラクター同士がぶつかったかどうかを調べる仕組み**のことです。

弾が敵に当たった、プレイヤーが壁にぶつかった、といったことを判断する、
ゲームを作る上でとても大事な部分です。

## Scratchで使えるブロック

| ブロック | 何を調べる？ |
| :--- | :--- |
| ◯◯に触れた | そのスプライトや端、マウスのポインターに触れているか |
| ◯◯色に触れた | 決めた色に触れているか（背景の色などに使える） |
| ◯◯までの距離 | そのスプライトやマウスまでの距離（数字） |

どれも[条件](wiki:条件)として”もし◯◯なら”ブロックなどに入れて使います。

## 「触れた」は絵の形で判定される

Scratchの”◯◯に触れた”は、四角い枠ではなく**絵の中身の形**で判定されます。

透明な部分は触れていないことになるので、
コスチュームの余白が大きいと「当たっていないのに当たった判定になる」ことは起きにくい代わりに、
細長い絵などは思ったより当たりにくく感じることがあります。

## 距離を使う方法

”◯◯までの距離 < 30”のように距離で判定する方法もあります。

こちらは絵の形に関係なく、中心からの距離だけで判定するので、
丸いキャラクター同士ならこちらの方が自然に感じることが多いです。

## ゲームの面白さに直結する

当たり判定は、**少し甘くしておく方が気持ちいい**ことが多いです。

弾がギリギリ当たっていないのに当たったことにすると「当てた！」と気持ちよくなり、
逆に自分がやられる判定は少し小さくすると「避けた！」と嬉しくなります。

プロのゲームでも、見た目の絵と当たり判定の大きさをわざと変えていることがよくあります。
