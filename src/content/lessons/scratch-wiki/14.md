# フラグ

フラグとは、**「はい」か「いいえ」だけを覚えておく変数**のことです。

旗（flag）を上げているか下げているか、というイメージですね。

Scratchでは中に”YES”か”NO”という文字を入れて使います。

[変数](wiki:変数)

## 何に使うの？

**「今どういう状態か」を覚えておく**ために使います。

授業で作ったものだと、こんなものがありますね。

| 名前 | 覚えておくこと |
| :--- | :--- |
| IsShooting | 今、飛んでいる最中かどうか |
| IsHit | もう当たったかどうか |

名前を”Is◯◯”にすると「◯◯なのか？」という疑問の形になるので、
中身がYESかNOだと一目で分かります。フラグの名前はこの形にするのが定番です。

## 一度だけ反応させたい時の形

フラグが一番活躍するのはこの場面です。

例えば「敵に当たったらダメージを与える」を作ると、
触れている間ずっとダメージが入ってしまいます。
Scratchは1秒間に約30回プログラムを動かすからですね。

[フレーム](wiki:フレーム)

そこでフラグを使って、次の形にします。

1. 条件に「かつ IsHit = NO」を足す（**まだ当たっていない時だけ**動く）
2. 動いたら「IsHitを YES にする」（当たったことを覚える）
3. 離れたら「IsHitを NO にする」（元に戻す）

この3つがセットです。**1つでも欠けると動かなくなる**ので、
必ず3つそろっているか確かめましょう。

[条件](wiki:条件)

## 気を付けること

### 元に戻し忘れない

一番多い失敗が、3番の「元に戻す」を忘れることです。

一度YESになったきり戻らないので、**2回目から反応しなくなります**。
「最初の1回しか当たらない」という時は、まずここを疑ってみてください。

### 初期化を忘れない

”🏴が押されたとき”でNOに戻しておかないと、
前に遊んだ時のYESが残ったまま始まってしまいます。

[初期化](wiki:初期化（しょきか）)

### 大文字と小文字は区別されない

Scratchの”◯ = ◯”ブロックは、大文字と小文字を区別しません。

なので”YES”と書いても”Yes”と書いても同じものとして扱われます。
授業の資料でも両方が混ざっていますが、どちらでも動くので安心してください。

ただし**自分のプロジェクトの中では、どちらかに揃えておく**方が読みやすいですよ。
