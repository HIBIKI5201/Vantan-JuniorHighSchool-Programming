# Scratch操作方法説明

# ステージ

右上の画面は「ステージ」と呼ばれます。
ここは実際のゲーム画面で、作ったゲームが遊べる所です。

![image.png](/lessons/taiken-jugyo/02/image-0.png)

絵をドラッグすると、ステージの上で好きな場所に動かせます。
動かしてみましょう！

# ブロックパレット

左側の画面は「ブロックパレット」と呼ばれます。
ここにはプログラムのブロックが沢山あります。

![image.png](/lessons/taiken-jugyo/02/image-1.png)

左側のカテゴリーを押すと、ブロックの種類を切り替えられます。
使いたいブロックをコードの画面へドラッグして置いてみましょう。
置いたブロックを消したい時は、ブロックパレットへドラッグして戻します。

# コード

真ん中の画面は「コード」と呼ばれます。
ここにブロックを置いてプログラミングをします。

![image.png](/lessons/taiken-jugyo/02/image-2.png)

ブロックをドラッグしてつなげたり、場所を移動したりできます。
つなげたブロックを押すと、プログラムが動きます。
ブロックを動かして、どんなふうに動きが変わるか試してみましょう！
